## 프로젝트

| 프로젝트 | 문제 | 본인 담당 | 결과 |
|---|---|---|---|
| **넉터**<br>농구 매칭 앱 | 농구 동호회 운영진이 게스트 모집, 친선전 섭외, 체육관 대관을 단톡방과 전화로 조율하던 문제 | 5명 팀에서 앱, 웹, 서버 개발과 배포, 장애 대응 | 2026-08-19 App Store, Google Play, 웹 출시<br>가입 회원 500+ |
| **에게**<br>건물 운영 3D 디지털트윈 | LG전자 ES사업본부(BECON) 출제 과제. 건물 운영자가 공간과 설비 상태를 직관적으로 파악하기 어려운 문제 | 4명 팀의 팀장, 웹, 서버리스 API, 도면 인식 모델 | PNU × AWS Maestro AI 해커톤 최우수상 |
| **BBB**<br>BusBuddyBuddy | 학생이 통학버스 지연과 정류장 변경을 미리 확인하기 어려운 문제 | 승객 앱, 백엔드, CI/CD | 수상 5건(CoShow 2025 차세대통신단장상 등) |

각 프로젝트의 문제 정의, 서버 구성, 트러블슈팅은 [포트폴리오 웹](https://taehun2123.github.io/)에 있습니다.
